准备 Windows 安装包时，在系统设置中查看系统类型。然后进入 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases) 或 [FlClash](https://github.com/chen08209/FlClash/releases) 的发行页，选择符合当前系统和架构的资产。

## 先完成安装，再调整配置

阅读发行说明中的安装要求。EXE 可能是安装程序，也可能直接运行；ZIP 的用途也应结合文件名判断。不要把源码压缩包当成便携版。安装后先确认客户端能正常打开，暂时保留默认设置。

## 导入和启动

在配置或订阅页面添加兼容链接，等待拉取完成。确认配置中有代理组，启用该条目，选择规则模式和一个可用节点，再按客户端说明打开系统代理。一次只运行一个代理客户端，便于排除端口和代理设置冲突。

访问目标网页，同时打开连接记录观察请求。如果页面失败，记录目标域名、错误提示与时间，再更换一个节点进行对照。一次改变一项设置，能看清变化来自哪里。

## 某个程序不走代理

系统代理只影响遵循这些设置的应用。浏览器正常而单个程序失败时，先检查程序自身的代理设置与连接记录，再阅读客户端关于 TUN 等接管方式的说明。全局模式也不会让原本绕过客户端的流量自动进入内核。

退出客户端后，如果普通网站也不能访问，检查 Windows 是否残留指向已停止程序的手动代理。更新前备份自定义规则，迁移结束后再清理旧目录。常用入口在[电脑版栏目](../../desktop/)。

参考：[Clash Verge Rev 文档](https://clash-verge-rev.github.io/)。
